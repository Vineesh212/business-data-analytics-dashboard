## 📊 Workbook Structure — 6 Sheets

### Sheet 1 — Client Jobs
Tracks all move jobs handled by Mc Transfer.

| Column | Description |
|--------|-------------|
| Job ID | Unique identifier (MT2001–MT2035) |
| Client Name | Name of the client |
| Designer / Referral | How the client was referred |
| Job Type | Residential Move, Commercial Move, Interior Install, Storage Delivery, Furniture Receiving |
| Origin City | Where the move starts |
| Destination City | Where the move ends |
| Scheduled Date | Planned date of the job |
| Items Count | Number of items being moved |
| Job Value ($) | Revenue generated by the job |
| Crew Assigned | Team A, B, or C |
| Job Status | Completed, In Progress, Scheduled, Cancelled |
| Notes | Additional context |

**Key metrics:**
- 30 jobs tracked (MT2001–MT2030)
- Total Revenue: $152,550
- Completion Rate: 56.7%
- Conditional formatting on Job Status column

### Sheet 2 — Storage Inventory
Tracks all furniture and antique items currently in Mc storage facility.

| Column | Description |
|--------|-------------|
| Item ID | Unique identifier (ST001–ST025) |
| Item Description | Name of the item |
| Category | Furniture, Artwork, Antique, Lighting, Accessories, Outdoor |
| Client Owner | Which client owns the item |
| Storage Bay | Physical location in warehouse |
| Date Received | When the item arrived |
| Condition | Excellent, Good, Fair, Damaged |
| Value ($) | Estimated item value |
| Days in Storage | =TODAY()-Date Received (auto-updates daily) |
| Storage Status | New Arrival, Standard, Long Term Storage (auto-calculated) |

**Key formulas used:**
```excel
Days in Storage: =TODAY()-F4
Storage Status:  =IF(I4>90,"Long Term Storage",IF(I4>30,"Standard","New Arrival"))
```

**Key metrics:**
- 25 items tracked
- Total Storage Value: $116,300
- 11 Excellent, 11 Good, 2 Fair, 1 Damaged
- Conditional formatting on Condition column

### Sheet 3 — Delivery Log
Tracks every delivery job with on-time performance, damage reports, and client satisfaction ratings.

| Column | Description |
|--------|-------------|
| Delivery ID | Unique identifier (DEL001–DEL030) |
| Job ID | Links to Client Jobs sheet |
| Client Name | Name of the client |
| Scheduled Date | Planned delivery date |
| Actual Date | Real delivery date |
| Driver | Assigned driver name |
| Items Delivered | Count of items in delivery |
| Damage Reported | Yes or No |
| On Time | Auto-calculated: Yes, No, or Pending |
| Client Rating (1-5) | Post-delivery satisfaction score |

**Key formula:**
```excel
On Time: =IF(E4="","Pending",IF(E4<=D4,"Yes","No"))
```

**Summary metrics (auto-calculated below data):**
```excel
On Time Rate:      =IFERROR(COUNTIF(I4:I33,"Yes")/COUNTIF(I4:I33,"<>Pending"),0)
Damage Rate:       =IFERROR(COUNTIF(H4:H33,"Yes")/COUNTA(H4:H33),0)
Avg Client Rating: =IFERROR(AVERAGEIF(J4:J33,">0"),0)
```

**Key metrics:**
- 30 deliveries tracked
- On Time Rate: 82.6%
- Damage Rate: 6.7%
- Average Client Rating: 4.4 / 5.0

### Sheet 4 — KPI Dashboard
Executive-level summary dashboard with auto-calculating KPIs and charts pulling from all data sheets.

**KPI Sections:**
- Job Performance (Total Jobs, Completed, In Progress, Scheduled, Cancelled, Total Revenue, Completion Rate)
- Delivery Performance (Total Deliveries, On Time, Late, Damage Reports, On Time Rate, Avg Rating)
- Storage Summary (Total Items, Excellent, Good, Damaged, Total Value, Avg Days)

**Charts included:**
- 🍩 Delivery Performance Donut Chart (On Time vs Late vs Pending)
- 🥧 Job Status Pie Chart (Completed vs In Progress vs Scheduled vs Cancelled)
- 📊 Top 5 Clients Bar Chart (by Job Value using VLOOKUP)

**Monthly Revenue KPIs:**
```excel
Week 1 Revenue: =SUMPRODUCT(('Client Jobs'!G3:G1000>=DATE(2026,6,1))*('Client Jobs'!G3:G1000<=DATE(2026,6,7))*('Client Jobs'!I3:I1000))
Peak Week:      =IF(AND(B45>=B46,B45>=B47,B45>=B48),"Week 1",IF(...))
W2 vs W1 Growth: =IFERROR((B46-B45)/B45,0)
```

**Weekly Revenue Results:**
| Week | Revenue |
|------|---------|
| Week 1 (Jun 1–7) | $32,750 |
| Week 2 (Jun 8–14) | $47,600 |
| Week 3 (Jun 15–21) | $41,400 |
